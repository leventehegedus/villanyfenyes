# Villanyfényes bajnokság viewer

Unofficial, read-only static SPA for the Villanyfényes bajnokság (amateur football, Budapest). A build-time ingest turns the public HTML pages into static JSON in `public/data/`; the app reads only those files.

## Stack

React 18, strict TypeScript 5.9, Vite, Tailwind v4, shadcn/ui (Radix), TanStack Query 5, React Router 7, Zod 4, cheerio (ingest only), Vitest, Playwright, pnpm, Node 22.

## Commands

- `pnpm dev` / `pnpm build` / `pnpm preview`
- `pnpm typecheck` / `pnpm lint` / `pnpm test` (Vitest, dot reporter) / `pnpm dup` (jscpd, 3 %)
- `pnpm e2e` (Playwright smoke test on `e2e/fixtures/data`)
- `pnpm ingest` (current season) · `pnpm ingest --season <id>` (backfill) · `pnpm ingest --dry-run` (parse, gate, no write) · `pnpm ingest --teams-only` (rebuild `teams/*.json` and `leaderboard.json` from disk, no requests)

## Rules

- Server state only through TanStack Query; never fetch in `useEffect`.
- No `any`, no `as unknown as T`, no non-null `!`. Components small with typed props.
- HTML parsing only in `scripts/ingest/` (pure functions on strings, tested on `__fixtures__`). Model, schedule, stats, filters only in `src/lib/` (pure, tested). Components stay thin. No duplicate logic in components.
- Shared Zod schemas live in `src/lib/schema.ts`; the ingest imports them.
- `public/data/` is generated by `pnpm ingest`; never hand-edit it.
- Never fabricate data. Missing is shown as missing ("nincs adat"). Derived stats are labelled "computed from results".
- Only `villanyfenyesbajnoksag.hu` public pages, GET only, polite (UA with repo URL, 1 request at a time, delay, budget). No live calls in tests or CI except the scheduled ingest workflow.
- No accounts, tracking, analytics or CORS proxies. No secrets.
- UI strings via `src/i18n` (hu default, en). Code, comments, docs, commits in English.
- `localStorage` access always in try/catch (`src/lib/storage.ts`).
- Use jCodeMunch for code lookups; plain Read only for files you edit or small configs.

## Glossary

bajnokság/liga = league, codes `L1`, `L2A`-`L2B`, `L3A`-`L3D`, `L4A`-`L4D`, `L5A`-`L5H` · szezon = season (e.g. `2026 - Ősz`, numeric site id) · csapat = team · forduló = round (not published; we group by week) · `MSZ` played, `Gy` won, `D` drawn, `V` lost, `LG` goals for, `KG` goals against, `GK` goal difference, `Pont` points · feljutó/kieső = promotion/relegation marker · góllövő = scorer · tabella = standings · menetrend = fixture schedule · eredmény = result · `meta.generatedAt` = when the ingest produced the data · stale data = older than the threshold in `src/lib/config.ts`.

## Definition of done

`pnpm typecheck && pnpm lint && pnpm test && pnpm dup` pass; UI changes verified in the browser (Playwright MCP, mobile and desktop, both themes).

## Model routing

Subagents in `.claude/agents/`: `scout` (haiku: lookups, log summaries, mechanical edits, i18n entries), `builder` (sonnet: features, parsers, tests, UI), `reviewer` (opus: only a bug that survived two attempts, or the final review; justify each use in `docs/DECISIONS.md`). Subagents return short summaries.

## Token rules and handoff

Plan once, then execute; batch independent calls; never read lockfiles, `node_modules`, `dist`, coverage, `public/data` or whole HTML pages (extract fragments). Terse test reporters, read failures only. After each phase: checks, commit, update `docs/PROGRESS.md` (done, next, open decisions). A fresh session continues from this file plus `docs/PROGRESS.md`. Same failure three times: stop, write findings to `docs/PROGRESS.md`, ask.
