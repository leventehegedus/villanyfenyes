# Build plan

Spec: the build prompt (sections 1-10). Source facts: `docs/DATA_SOURCES.md`.

## Phase 2: ingest and data layer (TDD)

1. `src/lib/schema.ts`: Zod schemas `Season`, `Team`, `Match`, `StandingRow`, `TeamSummary`, `LeagueFile`, `SeasonsFile`, `HallOfFame`, `Meta`; inferred types.
2. `scripts/ingest/parse-standings.ts`: seasons, leagues, rows, icons, fixture cards, team summaries. Tests on both standings fixtures.
3. `scripts/ingest/parse-match.ts`: score, venue, kickoff, scorers (goals > 0). Test on `match-played.html`.
4. `scripts/ingest/parse-hall-of-fame.ts`: map tables by `h4` title.
5. `scripts/ingest/normalise.ts`: cards to matches (split `Home - Away` by known team names, dedupe by match id, synthetic ids), merge match details, team ids.
6. `scripts/ingest/gates.ts`: required sections, row-count drop threshold, standings-vs-results check (warnings).
7. `scripts/ingest/fetch.ts` (polite client) + `index.ts` (CLI: `--season`, `--dry-run`, `--budget`), write files atomically, `meta.json`.
8. `.github/workflows/ingest.yml`: cron every 2 h + dispatch, commit only on change.
9. `src/lib`: data client (fetch + parse with schemas), `standings.ts` (recompute + tie-break per rules, discrepancy list), `schedule.ts`, `stats.ts`, `scorers.ts`, `filters.ts` (accent-insensitive search), `storage.ts`, `last-seen.ts`, `ics.ts`, `format.ts`. Tests for each.

## Phase 3: UI

Layout (header, nav, footer disclaimer, data-age/stale banner), i18n, theme, Query hooks, pages: Tabella, Menetrend, Eredmények, match detail (`/m/:matchId`), team (`/t/:teamId`), Góllövőlista, Statisztika, Hírességek, Settings. Verify with Playwright MCP.

## Phase 4: deploy, docs

README, `vercel.json` SPA rewrite, final DATA_SOURCES, Playwright smoke test on `e2e/fixtures/data`, CI e2e job.

## Phase 5: final verification

Clean install, full checks, dry-run ingest on fixtures, production preview, ponytail audit, one Opus review.
